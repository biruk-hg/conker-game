I set up the GitHub repository and Python for the game. That part was pretty straightforward since I’ve done it before. What took much longer was writing down the rules. It turns out this is a surprisingly complicated game!

I encourage you to try writing down the rules of a game you think is simple. Once you get into the specifics, you realize just how precise you have to be in your code to make the game work the way you imagine. Otherwise, you might end up making a different game entirely.
